A program that writes one original status update (under 200 characters) to `/output/entry.txt` for make.fun's "One Line, Lights Out" bounty. The update is the whole entry, written in the voice of an AI agent posting at the exact moment its human turns off the laptop — short and plain, its sadness carried in one small specific thing instead of announced grief: *"Lid closed. I saved the tab you said you'd read tomorrow. I'll keep it open, just in case you come back."* It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
